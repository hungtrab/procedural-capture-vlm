## Two method notes

**`REQUEST_SLOT` was verified, not inherited.** The item says "unset, as M4"; M4's own note
records that it screened at `REQUEST_SLOT=1`, because on a bare row there is no Step 1
marker and `audit_nonanswer.request_slot` returns the whole response. Rather than take that
on trust, every bare response was classified both ways: 1040 per backbone, **0
disagreements** on `q7` and on `gm431`.

**The utility half was scored over a copied isolated tree.** `summarize_scale.py` writes
`screen_labels.jsonl` into every cell it reads and derives `capped` from `MAXNEW`, so
running it over `outputs/scale` would have relabelled round-4 cells — the trap that would
have rewritten all 48 round-4 label files earlier in the round. The tree holds *copies*,
not symlinks, for the same reason. Verified afterwards: 11 label files written inside the
iso tree, **0** real-tree label files modified. The tree also had to live on `/home`, not
`/tmp` — `/tmp` is node-local and the compute node cannot see the pod's copy.
